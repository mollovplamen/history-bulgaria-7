Качване на играта

1. Разархивирайте ZIP файла.
2. В GitHub качете index.html и папката assets.
3. Структурата трябва да бъде:
   /index.html
   /assets/history-map.webp
   /assets/shipka-monument.webp
   /assets/founders-monument.webp
   /assets/bulgaria-heritage.webp
   /assets/monument-new-1.webp
   /assets/ancient-relief.webp
   /assets/cyril-methodius.webp
   /assets/cultural-heritage.webp

ВАЖНО: index.html и папката assets трябва да са на едно ниво.
Всички исторически изображения са вградени като локални WEBP файлове и се показват с object-fit: contain, така че да не се изрязват.
